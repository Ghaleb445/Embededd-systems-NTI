# Embedded Systems with C – NTI Training

## Overview

This repository contains the C programming assignments and projects completed during the **National Telecommunication Institute (NTI) Embedded Systems Training**. The projects focus on building a strong foundation in the C programming language, which is essential for embedded software development.

The assignments cover programming fundamentals, control structures, arrays, functions, structures, pointers, bitwise operations, sorting algorithms, and basic problem-solving techniques used in embedded systems.

---

## Topics Covered

* C Programming Basics
* Variables and Data Types
* Input and Output
* Conditional Statements (`if`, `switch`)
* Loops (`for`, `while`, `do-while`)
* Arrays
* Functions
* Structures
* Pointers
* Bitwise Operators
* Sorting Algorithms
* Memory Management Basics

---

## Projects Included

### 1. Employee Structure Management

* Create an employee structure.
* Store salary, bonus, and deductions.
* Calculate each employee's total salary.
* Calculate the company's total financial cost.

**Concepts**

* Structures
* Arrays of Structures
* User Input

---

### 2. Number Operations

A simple calculator that performs:

* Addition
* Subtraction
* Bitwise AND
* Bitwise OR
* Bitwise XOR

**Concepts**

* Arithmetic Operators
* Bitwise Operators

---

### 3. Pyramid Pattern

Prints a pyramid of stars based on the height entered by the user.

**Concepts**

* Nested Loops
* Pattern Printing

---

### 4. Infinite Sum Calculator

Continuously asks the user to enter two numbers and prints their sum until the program is terminated.

**Concepts**

* While Loop
* Infinite Loop

---

### 5. Login Validation System

Simple authentication system using arrays.

Features:

* Store usernames and passwords.
* Validate user credentials.
* Display login success or failure.

**Concepts**

* Arrays
* Strings
* Loops

---

### 6. Maximum & Minimum Using Functions

Reads four numbers and determines:

* Maximum value
* Minimum value

Implemented using two separate functions.

**Concepts**

* Functions
* Parameters
* Return Values

---

### 7. Simple Calculator Using Functions

Supports:

* Add
* Subtract
* Multiply
* Divide
* AND
* OR
* XOR
* NOT
* Remainder
* Increment
* Decrement

Each operation is implemented in a separate function.

**Concepts**

* Functions
* Switch Statement
* Modular Programming

---

### 8. Array Statistics

Reads 10 numbers into an array and calculates:

* Maximum
* Minimum

**Concepts**

* Arrays
* Loops

---

### 9. School Grade Management

Manages grades for three classes.

Calculates:

* Passed Students
* Failed Students
* Highest Grade
* Lowest Grade
* Average Grade

**Concepts**

* Arrays
* Loops
* Statistics

---

### 10. Bubble Sort

Sorts an integer array using the Bubble Sort algorithm.

**Concepts**

* Arrays
* Functions
* Sorting Algorithms

---

### 11. Pointer Swapping

Creates integer variables and pointers, then swaps the pointers while keeping the original values unchanged.

**Concepts**

* Pointers
* Memory Addresses
* Pointer Manipulation

## How to Compile

Using GDB:

```bash
gcc filename.c -o program
./program
```

Example:

```bash
gcc BubbleSort.c -o BubbleSort
./BubbleSort
```
